# ZoolGo — Customer app (`com.zoolgo.customer`)

Splash and onboarding, phone OTP login with the «your name» step, home (search, recent searches,
popular destinations), results with server sort and filters, trip detail, seat map with holds,
passengers, review with coupon and online / cash-to-driver payment, payment (mock provider in
development), my trips (upcoming / ongoing / past / cancelled), booking detail, e-ticket with QR
and PDF share, live tracking on OpenStreetMap, cancel with refund, change seat / trip, rating,
notifications, profile (edit, trip alerts, payment methods, privacy, logout, delete account).
