# ZoolGo — Broker app (`com.zoolgo.broker`)

Agent-office app: home KPIs and wallet balance, new booking (one way / round trip, seat map, women-only seats, hold countdown, review with wallet effect), bookings with QR tickets, cancel, change seat / trip, wallet ledger and top-ups (receipt upload), notifications, commissions, profile.

See the repository README for running and testing.
