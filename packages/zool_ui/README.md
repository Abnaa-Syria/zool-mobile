# zool_ui

ZoolGo design system from the Figma file "Test Design": Cairo font (OFL, static weights 400/600/700/800), mint background with the city header image, white 16px cards, red #9A1B2F actions, dark green #115233 amounts, Iconsax (vuesax) icons, the Figma seat component, bottom nav bar, e-ticket shape, OTP login, paged list and states.
